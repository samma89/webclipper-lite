# Clipfolio branding

The Clipfolio symbol combines overlapping folio shapes into a bold C. Indigo and mint connect the personal library with the act of capturing content, without tying the identity to a single capture format.

- `clipfolio-logo.png`: transparent, full-resolution master (1254 × 1254).
- `../icons/icon16.png`, `icon32.png`, `icon48.png`, `icon128.png`: production Chrome icons, resized from the master with macOS `sips`.
- Use the symbol alongside the name **Clipfolio** set in the interface's system sans-serif font.

Generated with the built-in image generation tool. Keep the master transparent and preserve its proportions.

## Generation prompt

Use case: logo-brand. Asset type: production brand symbol and Chrome extension icon for Clipfolio, a private personal library for web clippings with future screenshots and screen recordings. Design ONE bold, beautifully balanced abstract C formed by a pair of overlapping rounded capture frames / folio cards. A memorable unified silhouette with generous negative space and thick clean geometry that reads at 16 pixels. Modern editorial software identity, confident and calm. Use rich indigo with a small vivid mint accent on the overlapping card edge. Flat crisp vector-like graphic, no gradients, no shadows, no texture, no mockup, no presentation board. Center one large standalone mark with modest even padding on a truly transparent square background. No words, no letters outside the symbolic C, no scissors, no camera glyph, no tiny details. Deliver just one polished symbol.
